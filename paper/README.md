# Paper Track — Agent Evidence Probes

## Working title
**Agent Evidence Probes: A Reproducible Benchmark for Evidence Sufficiency Before Agent Action**

## Current status
Research prototype / paper preparation. Unlike EGA, this repository does not yet contain a full comparative experimental result suite suitable for arXiv submission.

## Contribution hypothesis
Test whether explicit evidence sufficiency probes can distinguish independently supported claims from unsupported or insufficiently supported claims before an agent proceeds.

## Required before submission
- multi-condition benchmark results
- baseline policies
- failure/abstention metrics
- ablations
- statistical uncertainty
- prior-art audit
- frozen reproducibility package

Do not label this repository as a publication until those requirements are met.
